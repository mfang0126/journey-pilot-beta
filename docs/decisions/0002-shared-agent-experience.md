# 0002：Android 优先，跨 Agent 共享经验

日期：2026-10-20。

状态：用户明确的产品方向；本文最初仅授权文档完善。后续本轮只读快路线开发授权见 [0003](0003-read-only-fast-route.md)，原始测试边界仍保留供追溯。

## 已确定的方向

任何具备本地命令调用能力的 Agent，经过统一入口操作 Android 手机后，执行经验由工具自动保存。其他 Agent 不依赖原聊天记录即可发现、参考或重放这些经验。验证过的经验直接执行，未验证经验辅助判断。

Phone Harness 保留为执行底层；skill 负责发现与使用指导，CLI 承载能力。经验属于共享存储，不属于某个模型或聊天。必要时用 Jev 确认，未知情况交还发起任务的 Agent。

首版先解决 Android，不同时建设网页适配、图搜索、自动子流程组合和地图界面。Kimi 研究保留供第二阶段使用。

## 为启动开发选定的默认方案

Python CLI、JSON Journey 文件、JSONL 事件、同机共享目录、设备串行执行、确定性条件检查、可选 Jev。首版不引入 app-automating、SQLite、向量库或常驻服务。

具体接口、阈值及首批验收任务由配套规格给出。这些是工程默认值，不是实测最优结论；开发者可以在保持验收目标和权限边界的前提下修正并记录理由，无需再次询问一般实现偏好。
