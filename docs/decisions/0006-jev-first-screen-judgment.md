# 0006：屏幕判断默认交给 Jev

2026-10-22，用户明确指示：「我希望默认全用 Jev……尽可能用 Jev。要搞明白怎么用，然后才能保证。」此前把 Jev 限为「仅中间辅助确认」是偏差，本决策取代该定位。

## 决策

- 屏幕判断默认走 Jev：页面识别、动作选择、异常处置。程序提供现场与**安全**候选选项，Jev 挑选并返回置信度；不发明坐标、文字或动作。
- 保险丝保留：置信度 <0.65 不执行，刷新现场重问一次，仍不行则结构化 handoff 交回当前 Agent。完全相同的候选视为布局知识过期，直接 handoff。最终成功仍由确定性后置条件判定。
- 大模型不逐步看屏下指令；只在 Jev abstain、不可用、无安全候选或需要新方法时接手。Jev 不可用按 `provider_unavailable` 处理，不判任务失败。
- 业务语义由任务脚本提供（候选含义、目标描述），不指望 Jev 从原始元素推断隐藏语义；喂给 Jev 的状态必须完整，空白节点带坐标保留。

## 依据

判断测试 36 次真实调用：动作选择 3/3、歧义 abstain 3/3、缺正文换像素读取 3/3、面板开合与正文有无 24/24；「页面有无 AI 入口」有入口页 0/3（无入口对照 3/3）证明隐藏语义必须由脚本供给。已测用例单次判断 0.30–0.41s（T2/T2b 未逐次计时）。证据与置信度分布见 REPORT。

## 边界

实现落在公共执行层（task_runtime/runner/douyin_ai），不改任务资格、晋级与 A–D 验收。真机 Jev 介入分支已现场验证（缺正文换像素通道，r_df065e36、r_b8477b7d 两次 completed）；真机歧义选目标分支与跨视频稳定性仍未验证。本轮未提交。
